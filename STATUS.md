E3.4 (#57) landed screen-embedding + label identity refinement: the additive async `EmbeddingPort` (+ real `EmbeddingAdapter` in `adapters/llm`) and a post-hoc gated `SamenessRefiner` cascade (recall floor → precision floor → label veto) wired into `CompositeStateIdentityStrategy` — strictly additive (NEVER-SPLIT; refinement-OFF == E2) and the synchronous `identify` contract is preserved. E3.5 (#58) landed the semantic duplicate / hidden-path detection differentiator: the post-hoc embedding-pass orchestrator `RefineIdentities` (walks the graph, embeds once per distinct a11y bucket via the budgeted/cached/redacted `EmbeddingPort` + new `EmbeddingCachePort`, feeds the unchanged `SamenessRefiner`) plus the pure `SemanticDuplicateDetector` (flags CROSS-identity convergence E2 misses, marks the less-prominent route `isHiddenPath`, emits the additive `DuplicatePathGroup`; precision-floor cross-identity scoping + a flag-time outcome-intent confirmation gate that also handles the #57 transitive label-veto bypass). The first `FakeEmbeddingPort` consumer carries the one-embedding-per-bucket assertion. E3.6 (#59, in review) is the capstone: the `BuildWorkflowMap` use-case assembles the five passes into one finalized `WorkflowMap` (order extract→intent→refine→detect→group; detect BEFORE group so the final objects carry `isHiddenPath`), binds the additive optional `WorkflowMap.duplicateGroups?`, and is wired at the `packages/api` composition root from resolved ports only (the `EmbeddingAdapter`/`createEmbeddingClient` are the only adapters named — the use-case imports none, NFR1). A new `RunBudgetMeter` is the single shared cross-pass counter both budget guards delegate to (additive ctor overload — existing tests untouched), bounding combined LLM+embedding spend by one ceiling. The CanonicalIdentityMap is consumed POST-HOC inside the detector (no `collaborators.ts`/`StartCrawlRun` change — correct per ADR-0005 §4.4). Two-layer E2E (application capstone + api wiring/port-purity) over fakes proves the success metric (≥1 semantic hidden/duplicate path), precision (structural convergence not flagged), shared-budget cap, degraded-safe one-map, determinism, and OTP redaction. | Closed: #54, #55, #56, #57, #58; In review: #59; Open: #3 (epic) |
